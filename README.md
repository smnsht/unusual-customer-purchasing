### CU Boulder, MS AI project in Data Mining

Discovering Unusual Customer Purchasing Behavior in Online Retail Transactions

Data source: [Kaggle](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)

## Project Setup

Create and activate a virtual environment, then install the core packages used by the notebooks.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install pandas numpy matplotlib jupyter kaggle
```

Next, download and extract the raw dataset into `data/`.

```powershell
.\scripts\download_data.ps1
```

After the dataset is available, run the notebooks in this order:

1. `notebooks/01_EDA.ipynb`
2. `notebooks/02_PreProcessing.ipynb`
3. `notebooks/03_FeatureEngineering.ipynb`

## Data Directory

The repository keeps an empty `data/` directory so notebook paths remain stable, but the contents of that folder are ignored by Git. Raw inputs and generated CSV files stay local and are not committed.

## Download The Dataset

The project expects the raw dataset at `data/online_retail_II.csv`.

Before downloading, install the Kaggle CLI and place your API token at `%USERPROFILE%\.kaggle\kaggle.json`.

```powershell
pip install kaggle
.\scripts\download_data.ps1
```

The script downloads the Kaggle archive into `data/`, extracts it there, and leaves the project ready for the preprocessing and feature engineering notebooks.

Processed files such as `transactions_uk_cleaned.csv`, `customer_features.csv`, `groupping_invoice.csv`, and `df_features.csv` are regenerated by the notebooks and are intentionally not tracked in Git.

## EDA Scope Note

United Kingdom represents about 94.7% of rows in the dataset. For this project EDA,
all non-UK rows are dropped in-place from `df` to keep analysis focused and reduce
cross-country noise.
